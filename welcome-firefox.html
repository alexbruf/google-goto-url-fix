Welcome to Google Goto Url Fix for Firefox

Open a Google Search results page and click the extension's toolbar icon. The blue ON badge means it is active.

ONExample: the extension is on

If the icon isn't visible, open Firefox's extensions menu (the puzzle-piece icon) and pin Google Goto Url Fix to the toolbar.

Some links take a moment to resolve. If you still see a Google /goto link, wait a moment, hover the result again, and then try copying it.

Use it in Private Windows (optional)

Firefox asks you to choose whether an extension can run in Private Windows. To allow it after installation:

  1. Open about:addons and select Extensions.
  2. Select Google Goto Url Fix to open its details.
  3. Next to Run in Private Windows, select Allow.

Illustration: choose Allow in Firefox's extension details.

This is optional. When allowed in Private Windows, the extension can read Google Search result links and send Google resolution requests there too.

You can close this tab when you're done. The extension's options also let you turn off nearby prefetching. See Mozilla's private-browsing guide for screenshots and more help.
