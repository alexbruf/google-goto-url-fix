Google Goto Url Fix

Resolve a few nearby links after scrolling pauses, so they may be ready before you hover. Turn this off to resolve links only when you interact with them.

Fallback service

If Google won't give up a link's destination, the extension can ask a paid service you have an account with. When this is on, the Google links that fail are sent to that service. Nothing is sent while this is set to "None". Your login is kept in this browser only and is not synced.

Find these under API Access at app.dataforseo.com. Failed links are sent together in one request.

Create a key in the cloro dashboard. cloro resolves one link per request.
